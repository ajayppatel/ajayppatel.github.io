# Games

Served at ajayppatel.com/games/. Each game is a self-contained folder:

- `games/<game-name>/index.html` — the playable page (keep asset paths relative)
- `games/<game-name>/icon.png` — 512×512 icon, used here and for "Add to Home Screen"
- add a card for it in `games/index.html`

Games save progress with localStorage only (no accounts).

## Games
- `word-vistas/` — Wordscapes-style word game (see its README to edit or add levels)
